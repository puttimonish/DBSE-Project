# 5-minute review demo
1. Open the React storefront and show catalog/search.
2. Sign in as customer.
3. Upload prescription → show OCR result/status.
4. Sign in as pharmacist → open Pharmacist console → approve prescription.
5. Add prescription medicine + normal medicine to cart.
6. Checkout → show order ID and status.
7. Open Swagger `/api/docs` and demonstrate health/catalog/auth/prescription/order endpoints.
8. Show Docker Compose services and explain separation of frontend, API, MySQL, OCR.
